Picture this: you have built the (hypothetical) dream AI dev pipeline.

Agents that:

- investigate the needs
- inspect the existing code
- churn out the specs
- implement them
- do the review
- test
- handle the deployment
- monitor production
- do user research
- iterate

All of it absolutely perfectly, without any human supervision, 100% through [Claude](https://claude.com/product/overview) tools.

... and then [Anthropic](https://www.anthropic.com/) botches an update, and for 3 days the agents become completely dumb.

Good luck.

That's why I always keep [a human in the loop](/work-with-me/).

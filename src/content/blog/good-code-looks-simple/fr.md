Le bon code paraît simple.
Le mauvais code paraît intelligent.

Mais écrire un code intelligent… qui paraît simple, c'est probablement l'une des choses les plus difficiles en développement.

Parce que derrière cette simplicité, il y a souvent :

- [un découpage propre](/fr/blog/coupling-is-the-worst-thing-in-a-codebase/)
- les bonnes abstractions
- uniquement les abstractions nécessaires
- des variables explicites
- une vraie cohérence d'ensemble
- des choix invisibles mais solides

Le code « impressionnant » est souvent facile à écrire.
Le code évident, lisible et durable demande beaucoup plus de maîtrise.

Ce code d'apparence simple, [c'est ce que je vise jour après jour](/fr/work-with-me/).

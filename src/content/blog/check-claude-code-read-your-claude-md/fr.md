Pour être sûr que [Claude Code](https://claude.com/product/claude-code) a lu au moins le [CLAUDE.md](https://code.claude.com/docs/en/memory) perso et le CLAUDE.md du projet (car parfois il semble [les zapper](/fr/blog/all-caps-driven-development/)) :

1. Dans le premier, tu lui demandes de toujours te saluer par ton prénom en début de conversation.
2. Dans le deuxième, tu dis comment tu t'appelles.

=> S'il te dit bonjour personnellement, c'est que c'est bon !

Ce petit garde-fou finit dans [chaque setup Claude Code que je configure](/fr/work-with-me/).

PS : la même technique peut être utilisée de plein de façons créatives, mais le concept reste le même :)
